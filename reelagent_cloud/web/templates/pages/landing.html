{# ------------------------------------------------------------ 功能矩阵 #}
功能矩阵

不是「一键生成」，而是一条可控的流水线

每个环节都留了人工介入的位置：提示词可改、单镜可重跑、成本可预估。

自动拆解剧本

一段素材 → 场景 / 镜头 / 景别 / 运镜 / 台词，输出结构化的分镜表，而不是黑盒一条视频。

跨镜头一致性

先为角色与场景生成基准设定图，之后每个分镜都以它为参考，并在提示词里嵌入固定外观描述。

质量评测闭环

色调稳定性、跨镜头相似度、基准图覆盖率等指标全部量化，低于阈值直接判失败并退还额度。

成本透明

生成前给出点数预估，生成后逐镜列出真实供应商成本与消耗点数，账本可对账、可追责。

分镜工作室

九宫格看关键帧，逐镜改提示词、单镜重跑。只重跑你勾选的那几个镜头，费用只按重跑量计算。

REST API 与 BYOK

专业版起开放 API Key，可把生成流程接进自己的系统；也能自带模型密钥，直接用自己的供应商额度。

三步流程

从素材到成片，只有三步

平均 3-8 分钟交付。中途可随时取消，未消耗的额度自动退还。

贴上素材

一段小说片段、一个产品卖点、一句口播稿都可以。系统会先拆出场景与镜头，并标注景别与运镜。

选定风格与画幅

电影感、日式动画、赛博朋克、水墨、写实记录五种风格预设；竖屏 9:16、横屏 16:9、方屏 1:1 任选。

生成、审片、微调

逐镜进度可见，关键帧与评测指标一并给出。不满意的镜头改提示词后单独重跑，不必整条重来。
