生成前你需要知道的三件事

1. 会先做设定图

系统先为角色与场景生成基准设定图（最多 {{ settings.max_base_images }} 张）， 之后每个分镜都以它为参考，避免长视频里「换脸」与场景漂移。

2. 中途可以取消

在生成中页面点击取消，未执行的部分不消耗额度，已消耗部分如因失败产生会全额退还。

3. 之后还能改

成片出来后进入分镜工作室，可逐镜修改提示词并只重跑选中的镜头，费用按重跑量计算。
