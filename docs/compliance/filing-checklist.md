# 备案清单（生成式 AI 双备案）

> 这份清单只做一件事：把「要交什么材料」和「仓库里已经有什么」对齐。
> 我无法代为提交，但可以把「哪些材料已经成稿、哪些还需要你补」列清楚，
> 免得法和务来回问同一个问题。

## 一、需要走的两道备案

| 备案 | 受理方 | 性质 | 前置条件 |
|---|---|---|---|
| 算法备案（互联网信息服务算法） | 国家网信办「互联网信息服务算法备案系统」 | 上线前完成 | 已完成 ICP 备案的域名 + 主体资质 |
| 生成式人工智能服务备案 | 属地省级网信办 | 上线前完成 | 算法备案受理/通过 + 内容安全机制材料 |

两者常被合称「双备案」，但受理主体与材料清单不同，不能互相替代。
具体表单与入口以当年官方最新发布为准 —— 这份清单只组织**我们能提供的部分**。

## 三、上线前必须先在代码里落实的两条

备案材料里最容易「说的和做的对不上」的是这两条，所以优先在代码里坐实：

1. **图像语义审核必须开启**
   ```bash
   REEL_COMPLIANCE__IMAGE_MODERATION=dashscope
   REEL_PROVIDERS__LLM__API_KEY=sk-...
   ```
   生产环境不配这条会**启动失败**（校验器强制）。理由：启发式只能发现纯色/过小，
   对涉黄涉暴涉政无感，把它当合规审核等于材料造假。

2. **日志留存 ≥180 天可自证**
   ```bash
   # 二选一
   REEL_OBSERVABILITY__LOG_SINK=both
   REEL_OBSERVABILITY__LOG_FILE=/var/log/reelagent/app.log
   # 或声明由外部平台留存
   REEL_OBSERVABILITY__LOG_EXTERNAL_RETENTION=true
   ```
   `log_retention_days` 低于 180 同样会启动失败。

## 四、提交前的自检

- [ ] 生产配置能正常启动（`python -m reelagent_cloud.server` 不报配置校验错误）
- [ ] 构造一条违规文本，确认任务失败且**没有产出成片**
- [ ] 生成一条真实成片，确认画面有「AI 生成」角标、`manifest.json` 有 `aigc` 块
- [ ] 调用 `DELETE /api/v1/me`，确认产物被清、组织被停用
- [ ] `GET /api/v1/audit/verify` 返回 `ok=true`
- [ ] 页脚能看到 ICP 备案号并链接到工信部

## 五、说明

以上不构成法律意见。备案材料的具体格式、字段与受理流程每年可能调整，
**以受理机关的当期要求为准**；这份清单的作用是把你手上已有的工程证据
对应到材料条目上，减少来回补件。
